# SwagLabs Test Automation

A Selenium WebDriver test automation framework in Java for the [SwagLabs / Sauce Demo](https://www.saucedemo.com/) e-commerce site, built using the **Page Object Model (POM)** design pattern with **TestNG**.

This is my first test automation project — feedback and suggestions are welcome!

## 🧰 Tech Stack

- **Language:** Java
- **Test Framework:** TestNG
- **Automation Tool:** Selenium WebDriver
- **Build Tool:** Maven
- **Browser:** Chrome (via `ChromeDriver`)
- **Design Pattern:** Page Object Model (POM), with a fluent/chained method style on page objects

## 📁 Project Structure

```
src
├── main/java/SwagLabs
│   ├── pages       # Page Object classes (e.g. LoginPage)
│   └── utiles      # Reusable utility/helper classes
│       ├── BrowserActions.java        # Browser-level actions (e.g. navigation)
│       ├── CustomSoftAssertion.java   # Custom soft assertion handling
│       ├── ElementActions.java        # Reusable element interactions
│       ├── Scrolling.java             # Scroll utilities
│       ├── Validations.java           # Validation helpers
│       └── Wait.java                  # Explicit wait utilities
└── test/java/Swaglabs/tests
    └── LoginTest.java   # Login test scenarios
.gitignore
pom.xml
```

## 🚀 Getting Started

### Prerequisites
- Java JDK installed
- Maven installed
- Google Chrome installed (tests run on Chrome via ChromeDriver)

### Running the tests
Clone the repository and run the test suite with Maven:

```bash
git clone https://github.com/Hiba-Mustafa/SwagLabs-TestAutomation.git
cd SwagLabs-TestAutomation
mvn test
```

Test results are generated by TestNG in the `target/surefire-reports` folder after each run.

## 🧪 Example Test

```java
@Test
public void successfulLogin() {
    new LoginPage(driver)
        .insertUsername("standard_user")
        .insertPassword("secret_sauce")
        .SubmitLoginButton()
        .assertSuccessLoginSoft();
}


Soft assertions are collected throughout the test and verified together in `@AfterMethod`, so a test can report multiple failures instead of stopping at the first one.
